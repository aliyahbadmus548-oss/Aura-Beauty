# Aura Beauty

**Reveal Your Natural Glow.**

Aura Beauty is a beauty and skincare website showcasing skincare, makeup and body care products.

## Website Features
- Home page
- About Us page
- Products page
- Contact page
- Responsive design
- Interactive contact form validation

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Purpose
This website was developed as a web development project to demonstrate HTML, CSS and JavaScript skills.
